# 章节标记（NovLang）

[Русский](../ru/markup.md) · [English](../en/markup.md) · **简体中文**

easy-digital-book 中的章节使用 **NovLang** 编写。这是一种面向小说文本、
类似 Markdown 的小型标记语言。一个文件就是一章。标记由
[`novlang-js`](https://www.npmjs.com/package/novlang-js) 库解析；本页说明它
支持哪些写法，以及应用如何使用解析结果。

NovLang **不是** Markdown：正文里没有列表、链接、代码、表格和标题。
解析器无法识别的内容都会按普通文本输出。不存在会导致章节无法打开的错误，
最坏的情况只是出现一个 ⚠ 警告。

## 速查表

| 内容        | 写法                         | 快捷键             |
| ----------- | ---------------------------- | ------------------ |
| 章节标题    | 第一行写 `# 标题`            | —                  |
| 段落        | 普通文本，段落之间空一行     | —                  |
| 斜体        | `*文本*`                     | Mod+I              |
| 粗体        | `**文本**`                   | Mod+B              |
| 粗斜体      | `***文本***`                 | —                  |
| 场景分隔    | 单独一行 `***`               | —                  |
| 图片        | `![说明](images/file.png)`   | 粘贴 / 拖放        |
| 脚注引用    | `[^1]`                       | Mod+Alt+F          |
| 脚注内容    | `[^1]: 脚注文本`             | （与引用一同插入） |
| 引文 / 书信 | 每行开头写 `> `              | —                  |
| 转义        | `\*`、`\[`、`\]`、`\!`、`\\` | —                  |

Mod 在 Windows 和 Linux 上是 Ctrl，在 macOS 上是 ⌘。

## 章节标题

```
# 第十二章 重返京城

本章第一段……
```

- 标题**只能写在章节的第一行**，`#` 后面必须有一个空格。
- 应用会用它作为侧边栏、EPUB 目录和页面 `<title>` 中的章节名。
- 没有标题时，章节显示为“第 N 章”（N 是它在书中的序号），并在全书警告中
  出现 ⚠。这个名称**不会**写入章节正文。
- 其他行里的 `#` 只是普通文本：第二行的 `# 迟到的标题` 会连同 `#` 原样显示。

## 段落

段落之间用**空行**分隔。单个换行不会结束段落：相邻的行会合并，由阅读器
自行折行。

```
段落的第一行
和它的后续内容。

这是第二段。
```

首行缩进和段间距由书籍主题决定，不需要用空格缩进。

## 斜体和粗体

```
这是*斜体*，这是**粗体**，这是***粗斜体***。
也可以嵌套：*轻轻地， **非常** 轻轻地*。
```

- Mod+I / Mod+B 用 `*` / `**` 包裹选中的文本，再按一次则去掉标记。
  没有选中内容时会插入一对标记，光标位于两者之间。
- 当内层标记与外层标记之间用空格隔开时（如上例），嵌套才会生效。若内层
  标记紧贴文字（`*a**b**c*`），NovLang 不会嵌套，而是拆成三段独立的斜体。
  文字不会丢失，但需要嵌套时请加空格。
- 对中文来说，这意味着嵌套时内层标记两侧的空格会保留在正文中。
  `*轻轻地，**非常**轻轻地*` 会变成三段斜体，而
  `**粗体里*斜体*粗体**` 会被错误拆分并产生警告。如果不想出现空格，
  请避免嵌套，改用相邻的独立片段，例如 `*轻轻地，*` `**非常**` `*轻轻地*`
  （中间不加空格）。
- 未闭合的标记（`开头 *没有结尾的斜体。`）会显示为普通星号，并产生警告
  “Unmatched '*' delimiter”。

## 场景分隔

三个星号**单独占一行**，前后各空一行：

```
……门在他身后关上了。

***

清晨很冷。
```

书中此处会显示居中的装饰符 `⁘`。

## 图片

```
![北境地图](images/map.png)
```

- `[]` 中的文字是替代说明（alt），可以留空：`![](images/map.png)`。
- 路径**相对于项目根目录**，所有图片都位于 `images/`。不能直接引用项目外的
  文件，需要先把图片导入项目。方法如下：
  - 把文件拖进编辑器，或从剪贴板粘贴图片（文件名为
    `pasted-YYYYMMDD-HHmmss.png`）——图片会立即以独立段落 `![](images/…)`
    插入到该位置，光标位于 `[]` 内；
  - 点击资源管理器“图片”分区中的 +——图片只会加入项目；要放进正文，请在
    图片的右键菜单中选择“插入文本”。

  应用会把文件复制到 `images/` 并清理文件名（拉丁字母、数字、`-`）。
  相同的图片不会重复保存。

- 支持 JPEG、PNG、GIF 和 WebP。导出时图片会按所选预设优化（尺寸、格式，
  可选灰度）。
- 图片也可以放在段落中间（`文字 ![](images/i.png) 文字`），但插图最好
  单独成段。
- 引用不存在的文件会产生“缺少图片”⚠。导出时这样的图片会被直接跳过。

## 脚注

```
师父谈起气[^1]时，仿佛那是可以触摸的东西。

[^1]: 气，中国传统中的生命能量。
```

- `[^1]` 是正文中的引用，`[^1]: …` 是脚注内容。定义可以写在本章任何位置，
  通常放在章末最方便。
- 标签不一定是数字：`[^qi]` 或 `[^a]` 也可以。
- **Mod+Alt+F** 会在光标处插入下一个可用编号的引用，在章末追加空定义
  `[^N]: `，并把光标移到那里。
- 脚注内容可以连续占多行，直到遇到空行。
- 脚注只在所属章节内有效。
- 没有定义的引用显示为 `[2]`，并产生警告
  `Footnote reference "^2" has no matching definition`。
- 在 Kindle 上脚注以弹窗形式打开；应用预览中脚注显示在章节底部。

## 引文和书信

在**每一行**开头写 `>` 和一个空格。只有 `>` 的一行用于在引文内部分段：

```
> 吾友：
>
> 我在京城给你写信。
> 这里一切如旧。

书信之后是普通正文。
```

## 转义

反斜杠会取消下一个字符的特殊含义，但只对 `*`、`[`、`]`、`!` 和 `\` 有效：

| 写法              | 结果               |
| ----------------- | ------------------ |
| `2 \* 3 = 6`      | `2 * 3 = 6`        |
| `\*不是斜体\*`    | `*不是斜体*`       |
| `\[^1\]`          | `[^1]`（不是脚注） |
| `\![不是图片](x)` | `![不是图片](x)`   |
| `C:\\Games`       | `C:\Games`         |

在其他字符前，`\` 会原样保留：`\>` 显示为 `\>`。

## NovLang 不支持的内容

链接 `[文本](url)`、列表、代码、表格、分隔线 `---`、章节内的小标题、
HTML 标签。这些都会按普通文本输出。排版（字体、缩进、对齐）不由标记决定，
而由书籍主题和可选的 `styles/custom.css` 文件（资源管理器中的“样式”）控制。

## 完整示例

```
# 第三章 来信

李明拿着信封犹豫良久，才把它拆开。
信纸上带着*茉莉*的香气。

> 兄长：
>
> 你读到这封信时，我已离开**青云宗**。
> 勿寻。

他把信读了三遍[^1]。

***

黎明时分，一辆马车已等在门外。

![宗门山门](images/gate.jpg)

[^1]: 按照习俗，兄长来信要读三遍，以示敬重。
```
