# Итог CSS-замеров на Paperwhite 3 — 2026-10-06

Для практических выводов о проверенных образцах на PW3 замеров достаточно.
Первый прогон содержит 142 теста, повторный — 57 уточняющих. Новая тестовая
книга и третий прогон для этих выводов не нужны. Неразличимые случаи
зафиксированы как ограничения имеющихся данных.

Основной итог: обычная книжная CSS-разметка оказывает ожидаемый эффект;
flex/grid и современные средства вроде CSS-переменных, calc и transform
в проверенных образцах эффекта не дали. Считать весь `@media` или
`::first-line` неработающими было бы ошибкой. Fixed оказывает эффект,
но с дефектами между страницами. Это выводы о конкретных образцах,
а не о всех значениях свойства или всех Kindle.

### Единицы

Повторные результаты подтверждают первую книгу при шрифте 3,
вертикально, на видимом `text-indent`:

- ДА: `em`, `rem`, `ex`, `px`, `pt`, `pc`, `cm`, `mm`, `in`, `%`
  (повторные 37–39, 41–47).
- НЕТ: `ch`, `vw`, `vh`, `vmin`, `vmax`, `dvw`, `dvh`, `svw`, `svh`,
  `lvw`, `lvh` (40, 48–57).

Это наличие/отсутствие отступа. Точные физические размеры и зависимость
от размера шрифта, root font или ориентации не измерены; ДА для rem
не подтверждает правильное масштабирование относительно корневого шрифта.

### Что сохраняется из первой книги

У неповторявшихся образцов остаются первоначальные наблюдения:

- ДА: большинство фонов/рамок/отступов, font-свойств, размеров,
  float/clear, списков, counters/content, opacity, z-index;
  `text-transform:uppercase` с кириллицей; обычные комбинаторы,
  атрибутные селекторы, `:not`, `:root`, `:empty`, `::before/after`,
  `::first-letter`, другие проверенные структурные псевдоклассы;
  `!important`, `box-shadow`.
- НЕТ: проверенные `:has/:is/:where`, CSS custom properties/`var`,
  `calc`, `transform`, `@layer`, `@page {margin:2em}`.
- `@font-face local(Caecilia)` — ДА для локального поиска, без проверки
  встраивания шрифтов. В приложение файлы шрифтов не добавлялись.
- Внутренний `@import` — ДА при наличии реального CSS `kindle:flow`;
  это не сетевой импорт и не поддержка импорта ресурсов приложением.
- `@namespace` — ДА для проверенного XHTML namespace/селектора.
- `@charset` и анимация `@keyframes` остаются неопределёнными.

Все эти выводы привязаны к точному CSS/HTML первого manifest. Повторного
подтверждения для неповторявшихся возможностей нет.

## Решение для проекта

1. Зафиксировать этот документ как актуальный итог исследования PW3.
   Первый отчёт остаётся историческим; его спорные строки заменяются
   выводами выше, исходные ответы сохраняются.
2. Для книжной темы использовать обычный поток, отступы, базовые шрифтовые
   свойства, рамки и проверенные структурные селекторы. На flex/grid,
   переменные, calc, transform и принудительную внутреннюю пагинацию
   по этим наблюдениям не полагаться. Это рекомендация для проверенного
   PW3-контекста, а не новая автоматическая перепись пользовательского CSS.
3. Не отключать `::first-line`, `word-wrap`, `display:block` или весь
   `@media` из-за первого прогона. Не трактовать исчезновение изображения,
   fixed-фрагментацию, недоступное состояние или НЕТ как ошибку синтаксиса.
4. Поведение checker и `kindleSupport` не меняется: он описывает оба
   целевых устройства, а данные получены только для PW3. Согласно принятой
   спецификации универсальные `supported/unsupported` требуют PW3 и PW12;
   `partial` пока остаётся честным общим статусом. Уточнение по одному
   свойству/значению не означает полной поддержки всей записи таблицы.
5. Наблюдения учитываются в документации и release checklist. Не вводить
   автоматически новый выбор устройства/прошивки или индивидуальные
   статусы: такой UI и модель данных требуют отдельного решения.
   Проверка PW12 и экспорт из packaged-сборок остаются отдельными release
   gates, но не мешают завершить анализ этих замеров сейчас.
